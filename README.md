# Генератор дипломов и грамот

Программа для Windows: берёт шаблон (.pptx или .pdf) и список людей из
Excel (.xlsx), создаёт один редактируемый PPTX со слайдом на каждую
непустую валидную строку (по умолчанию) или отдельные файлы. Исходные
файлы не изменяются. Работает полностью оффлайн.

В шаге 1 выбирают текстовые блоки/фрагменты PPTX или рамки PDF. Для
многослайдового PPTX явно выбирают один слайд диплома либо весь комплект;
предпросмотр PPTX приблизительный, точный вид проверяйте в PowerPoint.
На шаге 2 сопоставляют поля со столбцами, задают постоянный текст или
сохраняют исходный текст; ФИО обязательно по умолчанию, для других полей
обязательность включается отдельно. Пустые значения необязательных полей
оставляют текст шаблона. Здесь же можно сохранить пустой стандартный Excel,
а перед запуском проверить нужную строку, включая длинные значения.
Предупреждения о неподходящем тексте, отсутствующих шрифтах и ошибках
содержат номер строки Excel и слайда. Для сложного макета сохраните
привязки в `.mapping.json` рядом с шаблоном.

## Как получить exe на Windows

Готовый файл собирается автоматически на GitHub — ничего устанавливать
не нужно:

1. Откройте страницу репозитория в браузере.
2. Нажмите вкладку **Actions** (вверху, рядом с «Code», «Issues»…).
3. В списке слева выберите workflow **«Build Windows exe»**.
4. Откройте последний запуск с зелёной галочкой (верхний в списке).
5. Пролистайте страницу запуска вниз до блока **«Artifacts»**.
6. Нажмите **«DiplomGenerator-exe»** — скачается zip-архив.
7. Распакуйте архив — внутри `DiplomGenerator.exe`. Его можно копировать
   и запускать на любой Windows-машине, Python не требуется.

Готовые релизы лежат в разделе **Releases** справа на главной странице
репозитория — там exe можно скачать напрямую, без распаковки.

## Запуск из исходников

```
pip install -r requirements.txt
python run.py
```

## Сборка exe вручную на Windows

Запустите `build.bat` в папке проекта — появится
`dist\DiplomGenerator.exe`.

python make_test_data.py      # тестовые шаблоны и Excel в testdata/
