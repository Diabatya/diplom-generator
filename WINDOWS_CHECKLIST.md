# Проверка программы на Windows — чек-лист

Нужно: компьютер с Windows 10 или 11. Python устанавливать НЕ нужно.
Время: примерно 10–15 минут.

## Шаг 0. Скачать программу

1. Откройте страницу `github.com/Diabatya/diplom-generator` → вкладка **Actions**.
2. Нажмите на верхний запуск **Build Windows exe** с зелёной галочкой.
3. Пролистайте вниз до раздела **Artifacts**, скачайте `DiplomGenerator-exe`.
4. Распакуйте скачанный архив — внутри один файл `DiplomGenerator.exe`.
   Положите его в любую папку, например на Рабочий стол.

## Шаг 1. Запуск

1. Дважды кликните по `DiplomGenerator.exe`.
2. Если Windows покажет синее окно **«Windows защитила ваш компьютер»
   (SmartScreen)** — это ожидаемо: программа не имеет платной цифровой
   подписи. Нажмите **«Подробнее»** → **«Выполнить в любом случае»**.
   Если антивирус предупредит — разрешите запуск (это обычная реакция на
   неподписанные программы, собранные PyInstaller).
3. **Должно открыться окно программы** с заголовком «Генератор дипломов»
   и первым шагом — выбором шаблона.

   Если окно не появилось вообще или появилась ошибка — запишите точный
   текст ошибки и сделайте скриншот, дальше можно не идти.

## Шаг 2. Открыть шаблон

Возьмите любой файл-шаблон диплома в формате **PPTX** (или PDF).

1. Нажмите кнопку выбора файла шаблона, укажите ваш файл.
2. **Должно появиться:** превью первого слайда/страницы и список
   текстовых блоков (или рамка для выделения области — для PDF).

   Запишите: открылся ли файл, видно ли превью.

## Шаг 3. Привязать поле

1. Кликните по текстовому блоку в превью (или выберите из списка) и
   задайте имя поля, например `ФИО`. Для блока выберите режим замены.
2. **Должно появиться:** поле в списке привязанных полей.

## Шаг 4. Загрузить Excel

1. Перейдите на второй шаг, выберите Excel-файл со списком
   (первый столбец — ФИО, хотя бы 3–5 строк).
2. Привяжите поле `ФИО` к столбцу с фамилиями.
3. Выберите «Поле для имени файла» и при желании включите
   «только первое слово» — рядом должен показаться пример имени файла,
   например `Иванов.pdf`.
4. **Должно появиться:** предпросмотр строк из Excel.

## Шаг 5. Пример и генерация

1. Нажмите **«Сгенерировать пример»** — должен открыться/сохраниться
   один документ с подставленным именем. Откройте его и проверьте,
   что имя на месте и дизайн не поплыл.
2. Выберите папку для результатов и нажмите **«Запустить генерацию»**.
3. **Должно произойти:** в выбранной папке появятся файлы — по одному
   на строку Excel — и файл `generation_report.txt`.

   Запишите: сколько файлов создалось, открываются ли они,
   правильно ли подставлены данные.

## Шаг 6. Русские буквы в путях

1. Создайте папку с русским названием, например `Дипломы осень`.
2. Положите в неё шаблон и Excel, сгенерируйте результат туда же.
3. **Должно работать так же**, без ошибок про «файл не найден».

## Шаг 7. Повторная генерация (защита от перезаписи)

1. Запустите генерацию ещё раз в ту же папку, не удаляя файлы.
2. **Должен появиться диалог:** перезаписать / пропустить /
   добавить суффикс. Выберите «добавить суффикс».
3. **Должны появиться** файлы `Имя_2.ext` рядом со старыми,
   старые не должны измениться.
